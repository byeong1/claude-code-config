# Review

For review-style requests, use a code-review stance.

- Prioritize correctness, security, behavioral regressions, concurrency issues, data loss, and missing tests.
- Lead with findings ordered by severity.
- Include file and line references when available.
- Keep summaries secondary to findings.
- If no issues are found, say that clearly.
- Mention remaining test gaps or residual risk.
- Do not modify files unless the user explicitly asks for fixes.
