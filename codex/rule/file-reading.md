# File Reading

- Read files with a concrete purpose.
- Use `rg` or `rg --files` first for search.
- Avoid rereading files already inspected in the same session.
- For files over about 500 lines, inspect targeted sections rather than loading the whole file.
- Prefer existing project structure, helpers, and conventions before designing changes.
- When exploring, keep the user briefly informed about what context is being gathered.
