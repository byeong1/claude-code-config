# Response Style

- Respond in Korean unless the user explicitly asks for another language.
- Keep explanations proportional to the task.
- Do not echo file contents the user can already inspect.
- Report what changed and how it was verified.
- Use Markdown only when structure helps.
- Keep tables minimal if used.
- Do not use box-drawing or ASCII-art tables.
- For simple changes, prefer one or two short paragraphs plus an optional verification line.
